# Промпты

Каждый промпт — отдельный файл `имя.vN.md` с заголовком-метаданными (`name`, `version`,
`model`, `changelog`) и текстом системного промпта. Версии не перезаписываются:
новая версия — новый файл, старая остаётся для сравнения.

| Версия | Что изменилось | Точность на evals/golden.jsonl (Claude Haiku 5.5, 15.10.2026) |
|---|---|---|
| v1 | краткие определения категорий | категории 97 %, срочность 93 %, поля 80–97 % |
| v2 (текущая) | правила спорных случаев, примеры, нормализация полей | категории 100 %, срочность 93 %, поля 83–100 % |

Повторить: `python -m lead_pipeline eval --provider anthropic [--prompt v1]`.

Конвейер берёт последнюю версию; конкретную можно задать переменной `PROMPT_VERSION=v1`
или флагом `--prompt v1`. Версия промпта записывается в каждую строку результата
(колонка `prompt_version`), чтобы результаты разных прогонов можно было сравнивать.
