# Оценка качества

`golden.jsonl` — 30 размеченных вручную обращений (по 4–8 на категорию), включая спорные
случаи: цена + просьба записать (→ запись), вежливая претензия (→ жалоба), предложение
от компании (→ партнёрство) против массовой рассылки (→ спам).

`test_golden_accuracy.py` прогоняет набор через провайдер и проверяет точность
классификации. **Порог: точность категорий ≥ 90 %, срочности ≥ 80 %.** Точность полей
печатается в отчёте, но порогом не ограничена (поля сравниваются мягко: телефон и бюджет —
точно, текстовые — по нормализованному вхождению).

- `pytest` — по умолчанию прогон на эвристической заглушке (без сети). Это нижняя планка:
  заглушка знает только ключевые слова.
- `LEAD_EVAL_PROVIDER=anthropic pytest evals/` — прогон на Claude (нужен `ANTHROPIC_API_KEY`;
  без ключа тест пропускается). Версию промпта задаёт `PROMPT_VERSION`.
- `python -m lead_pipeline eval --provider anthropic --prompt v1` — отчёт с матрицей ошибок
  для сравнения версий промптов.
